# Google Play Listing Draft

## App Name

Finote

## Short Description

Catat pemasukan dan pengeluaran dengan cepat, aman, dan offline.

## Full Description

Finote membantu Anda mencatat keuangan pribadi tanpa akun dan tanpa koneksi
internet.

Fitur utama:

- Catat dan edit pemasukan serta pengeluaran.
- Kelola kategori keuangan.
- Cari dan filter histori transaksi.
- Lihat saldo, ringkasan, dan laporan.
- Export laporan ke Excel, Text, dan PDF.
- Backup dan restore database aplikasi.
- Import database dari aplikasi Catatan Keuangan lama.
- Pilih tema terang, gelap, atau mengikuti sistem.
- Lindungi aplikasi dengan PIN.

Data keuangan tersimpan secara lokal di perangkat. Finote tidak menjalankan
cloud sync, tidak memerlukan akun, dan tidak mengirim data ke layanan AI.
Backup, export, dan sharing dilakukan hanya ketika Anda memilihnya.

Receipt Scanner is not advertised in this first listing draft until its manual
release decision is complete.
