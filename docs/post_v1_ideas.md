# Post-v1 Ideas

Keep non-blocking tester requests here. Do not implement them during Phase 5H.

- Wallets / multiple accounts.
- Budgets.
- Recurring transactions.
- Cloud backup and multi-device sync.
- Optional user account.
- Advanced reports.
- AI receipt interpretation, categorization, or assistant.

Move an item into implementation only after v1 feedback validates the need and
the release roadmap explicitly accepts it.
